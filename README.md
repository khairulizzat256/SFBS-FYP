# Smart Facility Booking System (SFBS)

## Overview
The **Smart Facility Booking System (SFBS)** is a web application developed using **Java** and **Firebase**. This system is designed to streamline the facility booking process for places like **Club Community Cyberjaya**, reducing the need for face-to-face bookings and eliminating redundant booking issues. The application provides an efficient way for customers to view available time slots for specific sports facilities and manage their bookings seamlessly.

---

## Features
1. **Facility Booking**:
   - Customers can book available time slots for various sports facilities.
   - Facilities include:
     - Squash Court
     - Badminton Court
     - Tennis Table
     - Futsal Court
     - Basketball Court
     - Tennis Court

2. **Real-Time Availability**:
   - View real-time availability of facilities to avoid overbooking.

3. **User-Friendly Interface**:
   - Intuitive and easy-to-use interface for both customers and staff.

4. **Booking Management**:
   - Admins can manage bookings, view reports, and handle cancellations efficiently.

5. **Reduced Redundancy**:
   - Eliminates duplicate bookings and ensures fair access to facilities.

6. **Secure and Reliable**:
   - Built with Java and Firebase for robust security and scalability.

---
